put all these files under one project then compile and then simulate as per the given instruction below.
to run the entire system:
1. first compile
2. then in the transcript run:
      quit -sim
      vsim -voptargs="+acc" work.tb_system
      add wave -r sim:/tb_system/*
      run -all	


to run just ALU:
1. first compile
2. then in the transcript run:
      quit -sim
      vsim -voptargs=+acc work.tb_alu
      add wave -r sim:/tb_alu/*
      run -all
